# EM Frequency Chart

Visualizes Effective Mass vs Frequency data using a FastAPI backend and React frontend.

---

## Backend

```bash
cd backend
pip install -r requirements.txt
uvicorn main:app --reload --port 8000
```

API will be available at `http://localhost:8000/api/effective-mass`

---

## Frontend

```bash
cd frontend
npm install
npm run dev
```

App will be available at `http://localhost:5173`
